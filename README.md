# MoM Bot

This repository preserves the public MoM Bot lineage and contains the current
development version for TradeWars 2002.

## Versions

| Directory | Runtime version | Status |
| --- | --- | --- |
| [`mombot4.01p`](mombot4.01p/) | 4.01p | Historical public release from [`TW2002/mombot-public`](https://github.com/TW2002/mombot-public). |
| [`mombot4.7beta`](mombot4.7beta/) | 4.7beta | Historical development source previously published at [`TW2002/mombot`](https://github.com/TW2002/mombot). |
| [`mombot5.0`](mombot5.0/) | 5.1beta | Current development tree. |

The runtime version is defined by each tree's `mombot.ts` source, not merely by
its directory name. The 4.01p tree uses the older ready-to-run public layout;
the 4.7beta tree is source/development-oriented; and the 5.0 tree contains the
actively maintained source, build, release, and documentation workflows.

## Current development

Active source work belongs under [`mombot5.0/source`](mombot5.0/source/).
Release artifacts are assembled under [`mombot5.0/Release`](mombot5.0/Release/).
See [`mombot5.0/CHANGES_FROM_4.7BETA.md`](mombot5.0/CHANGES_FROM_4.7BETA.md)
for the major changes since 4.7beta.
