- wrob [minimum rob amount] {upgraded} {skipcim}            
    Travels universe robbing ports                          
                                                            
    [minimum rob amount]                                    
       - Amount that must be on port before attempting rob  
    [upgraded]                                              
       - Will only visit upgraded ports                     
    [skipcim]                                               
       - Will skip running CIM port report before running   
    [CLEAR_EMPTY]                                           
       - Will delete the empty port file
